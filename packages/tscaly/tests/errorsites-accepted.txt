# errorsites-accepted.txt — dead reporting sites whose ZERO has been established.
#
# `tools/errorsites.py report` counts every call of the checker's and the binder's
# reporting family over the stage-2 corpus and prints the sites that never fired. Most of
# those zeros are honest, and a lead list that keeps re-surfacing the same honest rows
# trains a reader to skip it — nocaller.py's own argument, one directory over. A row moves
# here when its reason has been ESTABLISHED, never because it looks plausible.
#
# Four fields, tab separated:   concept  function  the call as written  the reason
#
# ★ The key carries no line number on purpose: a site moves whenever anything above it in
# the file does, and a reason that expires on an unrelated edit is worse than none. It also
# means two identical calls in one function share one row, which is the right granularity
# for a reason and the wrong one for a count — the COUNT is keyed by site id.
#
# ★★ The two reasons that retire most rows, and neither is a defect:
#   OPTION   the report is under a compiler option the harness fixes. checker.scaly's
#            header lists them; `no_implicit_any`, `strict_null_checks`, `no_implicit_this`
#            and `use_unknown_in_catch_variables` are TRUE here, every other option FALSE.
#   ONE FILE a unit is a single file with no module resolution, so a report only an import
#            can reach across files is unreachable in this harness rather than unwritten.
#
# ★★★ A REASON IS A CLAIM AND IT CAN EXPIRE — an options record arriving later retires
# every OPTION row at once. Write the option's NAME, so the day it becomes settable the
# grep is one command.
